An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: a checklist saved in the browser with export and import, filters by kind, a spoiler setting that hides the hidden trophies until earned, a five-stage roadmap to the Platinum, the one missable trophy flagged, and a cited guide in the entrant's own words for every trophy.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network needed.
